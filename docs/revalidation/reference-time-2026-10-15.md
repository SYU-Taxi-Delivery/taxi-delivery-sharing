# 재검증 1: 모집글 수정의 기준시각 검증

검증일: 2026-10-15. 기준 코드: 7f6d944 및 이번에 보강한 PostContract 테스트.

## 결론

기존 구현은 요구사항을 충족한다. 운영 로직과 트랜잭션/잠금 정책의 수정 없이 테스트 8건을 보강했다. 이번 실행은 H2 기반 PostIntegrationTest 전체 47건이며 실패·오류·skip 없이 통과했다. 이번 재검증에서 MariaDB/MySQL이나 GitHub CI를 새로 실행한 것은 아니다.

## 코드 확인

- PostService.update는 변경 전후 referenceTime을 Instant로 비교한다. 실제로 달라질 때만 PostValidator.future와 동일 작성자/시각 중복 검사를 수행한다.
- referenceTime을 생략하거나 같은 시각을 다시 전송하면 기존 시각에 대한 `현재 + 10분` 생성 조건을 다시 적용하지 않는다. 같은 순간을 다른 UTC offset으로 표현해도 변경으로 간주하지 않는다.
- PostValidator.future는 `newReferenceTime.isAfter(now.plusSeconds(600))`를 사용한다. 수정한 기준시각이 현재보다 정확히 10분 뒤이거나 더 가까우면 거절하고, 10분을 초과해야 허용한다. 생성 API에서도 이 시간 조건을 적용한다.
- now는 기존 작성자/POST 잠금을 획득한 뒤 샘플링한다. 이번 확인에서 잠금 순서나 격리 수준을 변경하지 않았다.
- 제목 등 비핵심 필드만 수정할 때도 작성자 권한과 모집 상태는 확인한다. FINISHED/CANCELLED/REMOVED 상태의 수정을 허용하는 것은 아니다. 기준시각의 NULL/분 단위 형식 등 기본 데이터 검증도 유지한다.
